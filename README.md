# Proyecto Reproducible - Grupo 5

Este repositorio forma parte del componente práctico obligatorio sobre **Git, GitHub, README y proyectos reproducibles**. Su objetivo es demostrar cómo estructurar un proyecto sencillo y proporcionar instrucciones claras para que cualquier usuario pueda clonarlo y ejecutarlo en su propia computadora.

---

## Tecnologías utilizadas
* **HTML5 y JavaScript:** Estructura y lógica básica del proyecto web.
* **Git y GitHub:** Control de versiones y alojamiento remoto del repositorio.

---

##  Requisitos previos
Para poder ejecutar este proyecto en tu equipo, solo necesitas tener instalado un navegador web moderno (como Google Chrome, Mozilla Firefox, Microsoft Edge o Brave). No se requiere instalar ningún entorno de desarrollo complejo ni dependencias adicionales.

---
